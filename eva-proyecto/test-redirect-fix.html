🔄 Fix Redirección al Home - Observaciones

❌ Problema Identificado:

Síntoma: Después de crear una observación exitosamente, la página se redirige al home en lugar de permanecer en la vista de equipos.

🔍 Causa Raíz:

  • El callback onObservationAdded usaba window.location.reload()
  • El reload completo de la página puede causar problemas de routing
  • Posibles issues con estado de autenticación durante el reload
  • El router puede interpretar el reload como una navegación inválida

✅ Solución Aplicada:

Cambio: Reemplazar window.location.reload() con refreshDevices()

📝 Código Anterior (Problemático):

onObservationAdded={() => { // Refresh the equipment data after adding observation window.location.reload(); // Simple refresh for now }}

📝 Código Nuevo (Corregido):

onObservationAdded={() => { // Refresh the equipment data after adding observation refreshDevices(); }}

🎯 Beneficios de la Corrección:

  • ✅ No hay reload completo: La página no se recarga completamente
  • ✅ Mantiene el estado: Filtros, paginación y selecciones se conservan
  • ✅ Mejor UX: Transición suave sin parpadeo de página
  • ✅ Más rápido: Solo actualiza los datos necesarios
  • ✅ Sin redirecciones: Permanece en la vista actual
  • ✅ Mantiene autenticación: No hay problemas de estado de sesión

🔧 Flujo Corregido:

  1. Usuario hace clic en "Agregar Observación"
  2. Se abre el modal AddObservacionModal
  3. Usuario completa el formulario
  4. Se envía POST a /api/observaciones/equipo
  5. Backend responde con éxito
  6. Se muestra toast de éxito
  7. Se ejecuta refreshDevices() para actualizar datos
  8. Se cierra el modal
  9. Usuario permanece en la vista de equipos
  10. Los datos se actualizan sin reload

🧪 Cómo Probar la Corrección:

  1. Abrir la aplicación frontend y navegar a equipos médicos
  2. Hacer clic en "Agregar Observación" en cualquier equipo
  3. Completar el formulario con descripción y fecha
  4. Hacer clic en "Agregar Observación"
  5. Verificar que:
    • ✅ Aparece toast de éxito
    • ✅ El modal se cierra
    • ✅ Permaneces en la vista de equipos
    • ✅ NO hay redirección al home
    • ✅ Los datos se actualizan

🔍 Si el Problema Persiste:

Si aún hay redirecciones después de esta corrección, podría ser debido a:

  • Problemas de autenticación: Token expirado o inválido
  • Errores en refreshDevices(): El hook puede tener issues
  • Interceptors de Axios: Redirecciones automáticas en httpService
  • Router guards: Protecciones de rutas que redirigen

Solución adicional: Revisar los interceptors en httpService.js y los guards del router.
