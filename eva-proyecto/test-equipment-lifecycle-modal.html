Sistema de Pruebas para Modal de Hoja de Vida de Equipos Biomédicos

Hospital Universitario del Valle Evaristo García

📋 Información del Sistema

Este sistema de pruebas verifica la funcionalidad completa del modal de hoja de vida de equipos biomédicos, incluyendo:

  • Carga de datos completos desde la API del backend
  • Visualización de todas las secciones según especificaciones del informe
  • Generación de PDF con datos reales del equipo
  • Manejo de errores y estados de carga
  • Autenticación robusta con fallback a endpoints públicos
