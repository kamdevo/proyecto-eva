  INSTRUCCIONES DE CONFIGURACIÓN PARA CPANEL
═══════════════════════════════════════════════════

📋 PASOS PARA CONFIGURAR EVA EN CPANEL:

1️⃣ BACKEND (eva-backend/.env)
═══════════════════════════════════════════════════

Copia eva-backend/.env.production.example a eva-backend/.env

CAMBIOS OBLIGATORIOS:

✅ BASE DE DATOS:
   DB_HOST=localhost
   DB_DATABASE=uoxclxvl_gestionthuv2
   DB_USERNAME=uoxclxvl
   DB_PASSWORD=TU_CONTRASEÑA_MYSQL_CPANEL

✅ APP KEY (Generar en servidor):
   php artisan key:generate

✅ URLs DE PRODUCCIÓN:
   APP_URL=https://tu-dominio.com
   
✅ SANCTUM:
   SANCTUM_STATEFUL_DOMAINS=tu-dominio.com,www.tu-dominio.com

✅ CORS:
   CORS_ALLOWED_ORIGINS=https://tu-dominio.com,https://www.tu-dominio.com

✅ CORREO (Gmail):
   MAIL_USERNAME=evagestionalamedicina@gmail.com
   MAIL_PASSWORD=tu_contraseña_app_gmail
   NOTIFICATION_EMAIL=email-destinatario@ejemplo.com

⚠️ IMPORTANTE - NO CAMBIAR (configuración para cPanel):
   CACHE_DRIVER=file
   SESSION_DRIVER=database
   QUEUE_CONNECTION=database


2️⃣ FRONTEND (eva-frontend/.env.production)
═══════════════════════════════════════════════════

Copia eva-frontend/.env.production.example a eva-frontend/.env.production

CAMBIOS OBLIGATORIOS:

✅ URLs (reemplaza "tu-dominio.com"):
   VITE_API_URL=https://tu-dominio.com/api
   VITE_API_BASE_URL=https://tu-dominio.com
   VITE_SANCTUM_STATEFUL_DOMAINS=tu-dominio.com,www.tu-dominio.com
   VITE_SESSION_DOMAIN=tu-dominio.com


3️⃣ COMANDOS EN EL SERVIDOR CPANEL
═══════════════════════════════════════════════════

Después de subir los archivos al servidor:

cd eva-backend

# Generar APP_KEY
php artisan key:generate

# Migrar base de datos (si es primera vez)
php artisan migrate

# Crear enlace simbólico para archivos públicos
php artisan storage:link

# Limpiar cachés
php artisan config:clear
php artisan cache:clear
php artisan route:clear
php artisan view:clear

# Optimizar para producción
php artisan config:cache
php artisan route:cache
php artisan view:cache


4️⃣ BUILD DEL FRONTEND
═══════════════════════════════════════════════════

En tu máquina local (antes de subir):

cd eva-frontend
npm run build

Sube la carpeta "dist" generada al servidor cPanel


5️⃣ ESTRUCTURA DE CARPETAS EN CPANEL
═══════════════════════════════════════════════════

public_html/
  └── index.html (de eva-frontend/dist)
  └── assets/ (de eva-frontend/dist)
  
eva-backend/
  └── .env (configurado)
  └── public/
      └── storage/ (enlace simbólico)


6️⃣ PERMISOS DE CARPETAS
═══════════════════════════════════════════════════

Asegurar permisos 755 en:
- eva-backend/storage/
- eva-backend/bootstrap/cache/

Asegurar permisos 644 en:
- eva-backend/.env
