## 🔄 **SECUENCIA DE CONSTRUCCIÓN DE DATOS**

### **FASE 1: CONSULTA PRINCIPAL**
El sistema inicia obteniendo todos los datos directos de la tabla `equipos` usando el ID específico del equipo seleccionado. Esta consulta base proporciona aproximadamente el 60% de la información mostrada en el modal.

**Datos Obtenidos en Fase 1:**
- Todos los campos de identificación (ID, nombre, código, serie)
- Información técnica básica (marca, modelo, voltaje, frecuencia)
- Datos financieros (costo, vida útil, contrato)
- Todas las fechas críticas
- Estados operativos básicos
- Referencias a archivos

### **FASE 2: RESOLUCIÓN DE RELACIONES SIMPLES**
Para cada campo que es una clave foránea, el sistema realiza consultas JOIN para obtener las descripciones legibles correspondientes.

**Orden de Resolución:**
1. **Ubicación**: Servicio → Área → Sede (en cascada)
2. **Clasificaciones**: Tipo, tecnología, fuente, clasificaciones biomédicas y de riesgo
3. **Estados**: Estado operativo, disponibilidad
4. **Administrativo**: Tipo adquisición, propietario
5. **Mantenimiento**: Frecuencia, plan
6. **Regulatorio**: Registro INVIMA

### **FASE 3: RESOLUCIÓN DE RELACIONES COMPLEJAS**
Se resuelven las relaciones que requieren múltiples JOINs o consultas en cascada.

**Relaciones Complejas:**
- **Sede del Equipo**: `equipos.servicio_id → servicios.sede_id → sedes.name`
- **Responsable del Servicio**: `equipos.servicio_id → servicios.responsable_id → usuarios.nombre`
- **Centro de Costo**: `equipos.servicio_id → servicios.centro_costo_id → centros_costo.name`

### **FASE 4: PROCESAMIENTO DE ARCHIVOS**
El sistema procesa los campos que contienen referencias a archivos digitales.

**Procesamiento de Archivos:**
1. **Deserialización**: Convierte campos serializados (manuales, planos) en arrays utilizables
2. **Verificación de Existencia**: Confirma que los archivos referenciados existen físicamente
3. **Generación de URLs**: Crea enlaces accesibles para visualización o descarga
4. **Validación de Integridad**: Verifica que los archivos no estén corruptos

### **FASE 5: CÁLCULOS DERIVADOS**
Se realizan todos los cálculos basados en la información base obtenida.

**Cálculos Automáticos:**
1. **Temporales**: Edad del equipo, tiempo en servicio, días desde último mantenimiento
2. **Financieros**: Depreciación anual, depreciación acumulada, valor en libros
3. **Operativos**: Estado de calibración, próximas fechas de mantenimiento y calibración
4. **Estadísticos**: Indicadores de disponibilidad y confiabilidad

### **FASE 6: CONSULTAS DE HISTORIAL**
Si está habilitado, el sistema consulta tablas de historial para información complementaria.

**Consultas de Historial:**
1. **Mantenimientos**: Número total, último técnico, costos acumulados
2. **Movimientos**: Cambios de ubicación, historial de traslados
3. **Calibraciones**: Historial de verificaciones técnicas
4. **Modificaciones**: Cambios en la información del equipo

### **FASE 7: CONSOLIDACIÓN Y VALIDACIÓN**
Se consolida toda la información y se realizan validaciones finales antes de presentar al usuario.

**Validaciones Finales:**
- Coherencia entre fechas
- Existencia de archivos referenciados
- Validez de estados calculados
- Integridad de relaciones

## 🎨 **LÓGICA DE PRESENTACIÓN**

### **ORGANIZACIÓN VISUAL DE LA INFORMACIÓN**

#### **Estructura de Encabezado**
La información se presenta en un formato tabular estructurado que simula un documento oficial, con el logo institucional en la esquina superior izquierda y el título del documento ocupando el resto del encabezado.

#### **Agrupación por Bloques Temáticos**
La información se organiza en bloques lógicos que facilitan la lectura y comprensión:

1. **Bloque de Identificación**: Datos únicos del equipo
2. **Bloque Técnico**: Especificaciones y clasificaciones
3. **Bloque de Ubicación**: Información de localización
4. **Bloque Financiero**: Datos económicos y contractuales
5. **Bloque Temporal**: Cronología de fechas importantes
6. **Bloque Operativo**: Estados y disponibilidad
7. **Bloque de Documentación**: Archivos y documentos

#### **Presentación de Datos Calculados**
Los campos calculados se presentan de manera que sea evidente su naturaleza derivada:
- **Edad del Equipo**: Se muestra en años con decimales
- **Valores Financieros**: Se presentan con formato de moneda
- **Fechas Calculadas**: Se muestran con indicación de "Estimado" o "Calculado"

### **TRANSFORMACIONES DE DATOS PARA PRESENTACIÓN**

#### **Formateo de Fechas**
- Las fechas se presentan en formato legible (DD/MM/AAAA)
- Las fechas nulas se muestran como "No definido" o "Pendiente"
- Las fechas futuras calculadas se marcan como "Programado para"
