🧠 Understanding JavaScript Hoisting in React

The Problem: In JavaScript, function declarations are hoisted (moved to the top), but function expressions and arrow functions are not. When using React hooks like useCallback, the function is created as a variable assignment, which follows the same rules as let and const - they cannot be accessed before their declaration.

The Solution: Always define functions (especially those wrapped in useCallback) before any useEffect hooks that reference them. This ensures the function exists in memory before React tries to call it.

Best Practice: Order React hooks and functions as follows:

  1. State declarations (useState)
  2. Other hooks (usePDF, etc.)
  3. Function definitions (useCallback, regular functions)
  4. Effect hooks (useEffect)
  5. Render logic and JSX
